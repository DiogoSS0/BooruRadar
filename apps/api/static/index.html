About the project

A little context for the numbers.

BooruRadar is an independent, open-source index of public booru communities. It tracks their size and growth through aggregate metadata, without collecting images or videos.

Each measurement includes its source, date and evidence class. Missing or incompatible history is marked as unavailable.
